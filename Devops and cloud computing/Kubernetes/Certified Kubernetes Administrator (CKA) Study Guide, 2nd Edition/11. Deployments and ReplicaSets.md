# Obsidian Workflow 🛠️

## Daily Notes 🗓️

-   Create a daily note with the format `YYYY-MM-DD`
-   Use the **Daily Notes** plugin
-   Use templates for:
    -   Meetings 🤝
    -   Tasks ✅
    -   Journaling ✍️

## Templates 📝

-   **Meeting Template:**
    -   Date: `YYYY-MM-DD`
    -   Attendees:
    -   Agenda:
    -   Action Items:
    -   Notes:
-   **Task Template:**
    -   Task Name:
    -   Due Date:
    -   Priority:
    -   Status:
    -   Project:
-   **Journal Template:**
    -   Mood: 😊 😔 😠
    -   Gratitude:
    -   Highlights:
    -   Lessons Learned:

## Plugins ✨

-   **Daily Notes:** For creating daily notes.
-   **Templates:** For creating and using templates.
-   **Dataview:** For querying and displaying data.
-   **Kanban:** For managing tasks in a Kanban board.
-   **Calendar:** For viewing notes in a calendar.
-   **Backlinks:** To see links to the current note.
-   **Graph View:** Visualize connections between notes. 🧠

## File Management 📂

-   **Notes:** Store general notes and ideas.
-   **Projects:** Organize notes related to specific projects.
-   **Areas:** Organize notes related to areas of responsibility.
-   **Resources:** Store links, PDFs, and other resources. 📚

## Wiki-Links & Tags 🔗

-   Use **wiki-links** to connect related notes. `[[Note Title]]`
-   Use **tags** to categorize notes. `#tag`
