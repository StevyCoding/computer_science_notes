# Key points
- **Res health monitoring (RHM)**
	- monitor the health and availability of res like pods, nodes and containers.
	- help admin indentify and troubleshoots issue that may effect the sys perf and availability 
	- tool used
		- Dashboard
		- Prometheus
		- Grafana
	- RHM ensure that the sys is **resilient to failures** and can r**ecover quickly from any disruptions.**
	- it's important part of managing a cluster and ensures the sys :
		- **reliabilty**
		- **availabilty**
		- **scalability**
# Summary
Resource Health Monitoring (RHM) is the practice of tracking the health and availability of Kubernetes resources. By using tools like the Dashboard, Prometheus, and Grafana, administrators can ensure clusters remain reliable, available, and scalable, even when failures occur.
