# Key notes
 - Autoscaling
	 - adjust the res allocated to a deployment or set of pods based on demand
- Autoscaling type :
	- Horizontal Pod autoscaling (HPA)
			- increase/decrease replicas or adjust re req and limits, respectively
	- Vertical pod autoscaling (VPA)
			- increase/decrease replicas or adjust re req and limits, respectively
	- cluster autoscaling for efficient res allocation and ensure app responsiveness 
	- useful to handle variable worload or sudden spikes in traffics
