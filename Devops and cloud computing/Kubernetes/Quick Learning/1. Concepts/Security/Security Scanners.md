# Questions
* What is a container security scanner?
* Why use security scanners for container images?
* Which popular scanners exist?
* What features do they offer?
# Key points
* Identify vulnerabilities and potential security threats in container images **befor deployment**.
* **Popular security scanners:**
  * Aqua Security
  * Twistlock
  * Sysdig Secure
  * Trivy
  * Anchore Engine
  * OpenSCAP
* **Features offered:**
  * Vulnerability scanning
  * Compliance checks
  * Runtime protection
* By using these scanners, org can ensure **security & integrity** of their k8s deployment and minimize risk of **security breaches & data loss**.
# Summary
Container security scanners help **detect vulnerabilities & enforce compliance** in container images before deployment. Popular tools like Aqua, Twistlock, Sysdig Secure, Trivy, Anchore, & OpenSCAP provide **vuln scanning, compliance checks, and runtime protection**, enabling orgs to secure k8s deployments and reduce risk of breaches or data loss.
