# What’s FinOps 🚀

**FinOps** is about teams collaborating effectively. 🤝

-   Teams need to collaborate
-   Decisions are driven by the business value of cloud 💰
-   Everyone takes ownership for their cloud usage 🙋‍♀️🙋‍♂️

Key Concepts:

-   Management Groups
-   Subscriptions
-   Resource Groups
-   Resources
