        ```java
        import java.io.IOException;

            public static void main(String[] args) {

                    FileInputStream fis = new FileInputStream("myFile.txt"); // Be sure "myFile.txt" exists
                    int byteRead = fis.read(); // Reads one byte

                    fis.close();
                } catch (IOException e) {
                    e.printStackTrace();
                }
            }
        }
        ```
        (And similarly for writing)

    *   **Serialization Example:**
        ```java
        import java.io.FileOutputStream;
        import java.io.IOException;
        import java.io.ObjectOutputStream;

        public class SerializationExample {
            public static void main(String[] args) {
                try {
                    Person person = new Person("Alice", 30);
                    ObjectOutputStream oos = new ObjectOutputStream(new FileOutputStream("person.obj"));
                    oos.writeObject(person);
                    oos.close();
                    System.out.println("Object serialized to person.obj");
                } catch (IOException e) {
                    e.printStackTrace();
                }
            }
        }
        ```
        (Include a basic `Person` class for this)

2.  **Focus on Trade-offs:** Emphasize the *reasons* behind choosing one API over another. For example:

    *   **NIO vs. Traditional I/O:** NIO’s non-blocking I/O is much more efficient for servers handling many concurrent connections. Traditional streams are simpler for basic file reading/writing tasks.
    *   **Byte Streams vs. Character Streams:** Character streams handle Unicode properly, making them better for text processing. Byte streams are suitable for binary data.
