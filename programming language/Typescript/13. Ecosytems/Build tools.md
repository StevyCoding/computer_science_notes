🚀 **Task Runners**

Task runners automatically execute commands and carry out processes behind the scenes, helping you automate your workflow by performing mundane, repetitive tasks.

Common usages of task runners include:

*   Spinning up development servers
*   Compiling code (e.g., SCSS to CSS)
*   Running linters
*   Serving files from a local port on your computer
*   And many more!
