# Integrating Chakra UI in Next.js

## Introduction to Chakra UI

- Chakra UI is an open-source component library for building accessible and customizable user interfaces.
- Key features of Chakra UI:
  - Accessibility: Provides pre-built accessible components.
  - Theming: Allows customizing the default theme.
  - Light/Dark Mode: Supports automatic light/dark mode based on user preferences.
  - Composability: Enables building custom components on top of Chakra UI.
  - TypeScript Support: Provides first-class TypeScript integration.

## Integrating Chakra UI in a Next.js App

1. **Install Dependencies**:
   ```bash
   yarn add @chakra-ui/react @emotion/react@^11 @emotion/styled@^11 framer-motion@^4 @chakra-ui/icons
   ```

2. **Wrap the App with the Chakra Provider**:
   In `pages/_app.js`:
   ```jsx
   import { ChakraProvider, extendTheme } from '@chakra-ui/react';

   const customTheme = extendTheme({
     colors: {
       brand: {
         100: '#ffebee',
         200: '#e57373',
         300: '#f44336',
         400: '#e53935',
       },
     },
   });

   function MyApp({ Component, pageProps }) {
     return (
       <ChakraProvider theme={customTheme}>
         <Component {...pageProps} />
       </ChakraProvider>
     );
   }

   export default MyApp;
   ```

3. **Use Chakra UI Components**:
   In `pages/index.js`:
   ```jsx
   import { VStack, Button } from '@chakra-ui/react';

   export default function Home() {
     return (
       <VStack padding="10">
         <Button backgroundColor="brand.100">brand.100</Button>
         <Button backgroundColor="brand.200">brand.200</Button>
         <Button backgroundColor="brand.300">brand.300</Button>
         <Button backgroundColor="brand.400">brand.400</Button>
       </VStack>
     );
   }
   ```

4. **Implement Dark/Light Mode**:
   In `pages/_document.js`:
   ```jsx
   import { ColorModeScript } from '@chakra-ui/react';
   import NextDocument, { Html, Head, Main, NextScript } from 'next/document';
   import { extendTheme } from '@chakra-ui/react';

   const config = {
     useSystemColorMode: true,
   };

   const theme = extendTheme({ config });

   export default class Document extends NextDocument {
     render() {
       return (
         <Html lang="en">
           <Head />
           <body>
             <ColorModeScript initialColorMode={theme.config.initialColorMode} />
             <Main />
             <NextScript />
           </body>
         </Html>
       );
     }
   }
   ```

   In `pages/index.js`:

   ```jsx
   import { VStack, Button, Text, useColorMode } from '@chakra-ui/react';

   export default function Home() {
     const { colorMode, toggleColorMode } = useColorMode();

     return (
       <VStack padding="10">
         <Text fontSize="4xl" fontWeight="bold" as="h1">
           Chakra UI
         </Text>
         <Text fontSize="2xl" fontWeight="semibold" as="h2">
           Rendering in {colorMode} mode
         </Text>
         <Button aria-label="UI Theme" onClick={toggleColorMode}>
           Toggle {colorMode === 'light' ? 'dark' : 'light'} mode
         </Button>
       </VStack>
     );
   }
   ```

By following these steps, you can integrate Chakra UI into your Next.js application and take advantage of its accessibility, theming, and dark/light mode features.

# Integrating TailwindCSS in Next.js

## Tailwind CSS: A Utility-First CSS Framework

- Tailwind CSS is a utility-first CSS framework that allows you to build any user interface using pre-made CSS classes.
- Unlike Chakra UI or Material UI, Tailwind CSS does not provide any JavaScript components. It's just a set of CSS classes.
- Key features of Tailwind CSS:
	-  Framework agnostic: Can be used with React, Vue, Angular, or even plain HTML/JavaScript.
	- Themeable: Customize all the variables to match your design tokens.
	- Dark/Light mode support: Easily enable or disable the dark theme.
	- Highly optimized: Removes unused CSS classes at build time.
	- Mobile-ready: Use specific class prefixes for mobile, tablet, or desktop styles.

## Integrating Tailwind CSS in a Next.js Project

1. **Install Dependencies**:
   ```bash
   yarn add -D autoprefixer postcss tailwindcss
   ```

   Also, install the `next-themes` library to manage the dark/light mode:

   ```bash
   yarn add next-themes
   ```

2. **Set up the Tailwind CSS Configuration**:
   ```bash
   npx tailwindcss init -p
   ```

   This will create the `tailwind.config.js` and `postcss.config.js` files.

3. **Configure Tailwind CSS**:
   In `tailwind.config.js`:
   ```javascript
   module.exports = {
     purge: ['./pages/**/*.{js,jsx}', './components/**/*.{js,jsx}'],
     darkMode: 'class',
     theme: {
       extend: {},
     },
     variants: {
       extend: {},
     },
     plugins: [],
   };
   ```
   - Enable the `purge` option to remove unused CSS classes.
   - Set `darkMode` to `'class'` to use the `dark` class on the `<html>` element.

4. **Import the Tailwind CSS Styles**:
   In `pages/_app.js`:
   ```javascript
   import 'tailwindcss/tailwind.css';

   function MyApp({ Component, pageProps }) {
     return <Component {...pageProps} />;
   }

   export default MyApp;
   ```

5. **Implement the Dark/Light Mode Switch**:
   In `pages/_app.js`:
   ```javascript
   import { ThemeProvider } from 'next-themes';
   import TopBar from '../components/TopBar';
   import 'tailwindcss/tailwind.css';

   function MyApp({ Component, pageProps }) {
     return (
       <ThemeProvider attribute="class">
         <div className="dark:bg-gray-900 bg-gray-50 w-full min-h-screen">
           <TopBar />
           <Component {...pageProps} />
         </div>
       </ThemeProvider>
     );
   }

   export default MyApp;
   ```
   - Use the `ThemeProvider` from `next-themes` to manage the dark/light mode.
   - Apply the `dark:bg-gray-900` and `bg-gray-50` classes to the main container.

6. **Create the `TopBar` and `ThemeSwitch` Components**:
   In `components/TopBar/index.js`:
   ```javascript
   import ThemeSwitch from '../ThemeSwitch';

   function TopBar() {
     return (
       <div className="w-full p-2 bg-green-500">
         <div className="w-10/12 m-auto">
           <ThemeSwitch />
         </div>
       </div>
     );
   }

   export default TopBar;
   ```

   In `components/ThemeSwitch/index.js`:

   ```javascript
   import { useTheme } from 'next-themes';

   function ThemeSwitch() {
     const { theme, setTheme } = useTheme();
     const dark = theme === 'dark';

     const toggleTheme = () => {
       setTheme(dark ? 'light' : 'dark');
     };

     if (typeof window === 'undefined') return null;

     return (
       <button
         onClick={toggleTheme}
         className="
           dark:bg-green-900 dark:bg-opacity-20 dark:text-gray-50
           bg-green-100 text-gray-500 pl-2 pr-2 rounded-md text-xs
           p-1"
       >
         Toggle theme
       </button>
     );
   }

   export default ThemeSwitch;
   ```

7. **Create the `UserCard` Component**:
   In `components/UserCard/index.js`:
   ```javascript
   import Link from 'next/link';

   function UserCard(props) {
     return (
       <Link href={`/user/${props.username}`} passHref>
         <div
           className="
             dark:bg-gray-800 bg-gray-100 cursor-pointer
             dark:text-white p-4 rounded-md text-center
             shadow-xl"
         >
           <img
             src={props.avatar}
             alt={props.username}
             className="w-16 bg-gray-400 rounded-full m-auto"
           />
           <div className="mt-2 font-bold">
             {props.first_name} {props.last_name}
           </div>
           <div className="font-light">{props.job_title}</div>
         </div>
       </Link>
     );
   }

   export default UserCard;
   ```

8. **Implement the Home Page**:
   In `pages/index.js`:
   ```javascript
   import UserCard from '../components/UserCard';
   import users from '../data/users';

   export default function Home() {
     return (
       <div className="sm:w-9/12 sm:m-auto pt-16 pb-16">
         <h1 className="dark:text-white text-5xl font-bold text-center">

             <div key={user.id}>
               <UserCard {...user} />
             </div>
           ))}
         </div>
       </div>
     );
   }
   ```

9. **Create the Individual Employee Page**:
   In `pages/user/[username].js`:
   ```javascript
   import Link from 'next/link';
   import users from '../../data/users';

   export function getStaticPaths() {
     const paths = users.map((user) => ({
       params: {
         username: user.username,
       },
     }));
     return {
       paths,
       fallback: false,
     };
   }

   export function getStaticProps({ params }) {
     const { username } = params;
     return {
       props: {
         user: users.find((user) => user.username === username),
       },
     };
   }

   function UserPage({ user }) {
     return (
       <div className="pt-0 sm:pt-16">
         {/* Render the user details using Tailwind CSS classes */}
       </div>
     );
   }

   export default UserPage;
   ```

By following these steps, you can integrate Tailwind CSS into your Next.js application and build the employee directory. The key differences compared to the Chakra UI implementation are:

1. **Utility-First Approach**: Tailwind CSS provides a set of utility classes that you compose to build the UI, instead of pre-built components.
2. **Theming**: Tailwind CSS allows you to customize the design by modifying the theme variables in the `tailwind.config.js` file.
3. **Dark/Light Mode**: Tailwind CSS supports dark mode by using the `dark:` prefix for classes. The `next-themes` library helps manage the mode switching.
4. **Optimization**: Tailwind CSS optimizes the final CSS bundle by removing unused classes during the build process.

# Integrating Headless UI

## What is Headless UI?

- Headless UI is a set of unstyled, accessible UI components provided by the Tailwind Labs team.
- It provides the dynamic functionality of UI components without any pre-defined styles.
- This allows developers to easily style the components using Tailwind CSS or any other CSS framework.

## Integrating Headless UI and Tailwind CSS

1. **Install Dependencies**:
   ```bash
   yarn add @headlessui/react classnames
   ```
   - `@headlessui/react` provides the Headless UI components.
   - `classnames` is a utility library to conditionally apply CSS classes.

2. **Create a Menu Component**:
   In `pages/index.js`:
   ```jsx
   import Link from 'next/link';
   import { Menu } from '@headlessui/react';
   import cx from 'classnames';

   const entries = [
     { name: 'Home', href: '/', enabled: true },
     { name: 'About', href: '/about', enabled: true },
     { name: 'Contact', href: '/contact', enabled: false },
   ];

   const { Button, Items, Item } = Menu;

   const MenuEntry = (props) => (
     <Item disabled={!props.enabled}>
       {({ active }) => (
         <Link href={props.href} passHref>
           <a
             className={cx(
               'w-full', 'p-2', 'rounded-lg', 'mt-2', 'mb-2',
               { 'opacity-50': !props.enabled, 'bg-blue-600': active, 'text-white': active }
             )}
           >
             {props.name}
           </a>
         </Link>
       )}
     </Item>
   );

   export default function Home() {
     return (
       <div className="w-9/12 m-auto pt-16 pb-16">
         <Menu>
           <Button className="bg-purple-500 text-white p-2 pl-4 pr-4 rounded-lg">My Menu</Button>
           <Items className="flex flex-col w-52 mt-4 p-2 rounded-xl shadow-lg">
             {entries.map((entry) => (
               <MenuEntry key={entry.name} {...entry} />
             ))}
           </Items>
         </Menu>
       </div>
     );
   }
   ```

3. **Style the Menu using Tailwind CSS**:
   - The `MenuEntry` component uses Tailwind CSS classes to style the menu items.
   - The `Button` and `Items` components from Headless UI are styled using Tailwind CSS classes as well.

4. **Implement Transitions**:
   ```jsx
   import { Menu, Transition } from '@headlessui/react';

   export default function Home() {
     return (
       <div className="w-9/12 m-auto pt-16 pb-16">
         <Menu>
           <Button className="bg-purple-500 text-white p-2 pl-4 pr-4 rounded-lg">My Menu</Button>
           <Transition
             enter="transition duration-100 ease-out"
             enterFrom="transform scale-95 opacity-0"
             enterTo="transform scale-100 opacity-100"
             leave="transition duration-75 ease-out"
             leaveFrom="transform scale-100 opacity-100"
             leaveTo="transform scale-95 opacity-0"
           >
             <Items className="flex flex-col w-52 mt-4 p-2 rounded-xl shadow-lg">
               {/* Menu items */}
             </Items>
           </Transition>
         </Menu>
       </div>
     );
   }
   ```
   - The `Transition` component from Headless UI adds smooth animations when the menu is opened and closed.

By integrating Headless UI and Tailwind CSS, you can create dynamic, accessible, and customizable UI components for your Next.js application. Headless UI provides the functionality, while Tailwind CSS allows you to style the components according to your design requirements.

This approach gives you more flexibility compared to using pre-styled UI component libraries like Chakra UI or Material UI. You can easily adapt the components to match the unique design of your application.

In summary, Headless UI and Tailwind CSS work well together, allowing you to build custom, accessible, and visually appealing user interfaces for your Next.js projects.
