State management is a crucial aspect of React and Next.js applications, enabling dynamic and interactive user interfaces. It involves handling dynamic data that drives UI changes, such as theme toggling, form inputs, or button interactions. While state management enhances user experience, it introduces complexity, leading to various solutions for better organization and simplicity.

In React, state management has evolved from class components with `setState` to modern React Hooks like `useState`. However, managing global state remains challenging due to React's unidirectional data flow, where state can only be passed down to child components, not up to parents.

This chapter explores two approaches to global state management:

1. **React Context APIs**: A built-in solution for sharing state across components.
2. **Redux**: An external library for centralized state management, applicable on both client and server sides.

Key topics covered include:

- Local state management
- Using Context APIs for global state
- Implementing Redux for state management

By the end, you'll understand the differences between local and global state management and how to effectively use Context APIs and Redux for global state in your applications.

# Local state management

Local state management in React refers to managing state that is scoped to a single component. A simple example is a `Counter` component that uses the `useState` Hook to manage its internal state. Here's the code for such a component:

```jsx
import React, { useState } from "react";

function Counter({ initialCount = 0 }) {
  const [count, setCount] = useState(initialCount);

  return (
    <div>
      <b>Count is: {count}</b><br />
      <button onClick={() => setCount(count + 1)}>Increment +</button>
      <button onClick={() => setCount(count - 1)}>Decrement -</button>
    </div>
  );
}

export default Counter;
```

### How It Works:

1. **`useState` Hook**:
   - `useState(initialCount)` initializes the `count` state with the value passed as `initialCount` (defaulting to `0` if not provided).
   - `setCount` is the function used to update the `count` state.

2. **State Updates**:
   - Clicking the "Increment +" button increases the `count` by 1.
   - Clicking the "Decrement -" button decreases the `count` by 1.

3. **Local Scope**:
   - The `count` state is local to the `Counter` component. It can be initialized by a parent component via the `initialCount` prop, but the parent cannot directly access or modify the `count` state.

### Use Cases for Local State:

- **Atom Components**: Small, reusable components (like buttons or inputs) often manage their own local state.
- **Loading States**: When fetching data, a `loading` state can be used to show a spinner until the data is ready.
- **Simple Interactions**: Local state is ideal for managing UI interactions that don't need to be shared across the application.

### Advantages of Local State:

- **Simplicity**: React's `useState` and `useReducer` Hooks make local state management straightforward.
- **No External Libraries Needed**: For most cases, you don't need additional tools or libraries.

### Limitations:

- **Component-Scoped**: Local state cannot be easily shared with other components. For global state (e.g., a shopping cart in an e-commerce app), you need solutions like Context API or Redux.

# Global State Management

- Refers to managing state that is shared across multiple components
- Necessary when local state is not enough, e.g., for a shopping cart

**Challenges**
- React's unidirectional data flow makes global state difficult to implement
- Components can only pass data down to children, not up to parents

**Solutions**
1. **Context API**
   - Built-in React feature for sharing state across components
   - Simple and effective for small to medium-sized apps

2. **Redux**
   - Powerful state management library
   - Provides a centralized store and predictable state updates
   - Suitable for large-scale applications

3. **Other Libraries**
   - Recoil, MobX, Apollo Client (with GraphQL) offer alternative approaches

**Key Takeaways**
- Global state is necessary when data needs to be shared across the application
- Context API is a lightweight solution, while Redux is better for complex state management
- Choose the approach that best fits your application's size and complexity

## Using the Context APIs

- The React Context API provides a simple and effective way to share state across components without the need for external libraries.
- It allows you to create a "context" that can be accessed by any component in the component tree.

**Key Steps:**

1. **Create a Context**:
   ```jsx
   const CartContext = createContext();
   ```

2. **Provide the Context**:
   Wrap your application with a `Provider` that holds the global state.
   ```jsx
   function App() {
     const [cart, setCart] = useState([]);

     const addToCart = (product) => {
       setCart([...cart, product]);
     };

     return (
       <CartContext.Provider value={{ cart, addToCart }}>
         <NavigationBar />
         <ProductList />
       </CartContext.Provider>
     );
   }
   ```

3. **Consume the Context**:
   Use the `useContext` Hook to access the global state in any component.
   ```jsx
   function ProductList() {
     const { addToCart } = useContext(CartContext);

     return (
       <div>
         {products.map((product) => (
           <button onClick={() => addToCart(product)}>Add to Cart</button>
         ))}
       </div>
     );
   }
   ```

**Key Benefits:**
- **Simplicity**: The Context API is a built-in React feature, making it easy to implement.
- **Effective for Small to Medium Apps**: The Context API is a lightweight solution suitable for applications with moderate global state complexity.

**Considerations:**
- For larger applications with more complex global state, Redux or other state management libraries may be more appropriate.
- The Context API can be less performant than Redux for high-frequency state updates, as it triggers re-renders in all consuming components.

By using the Context API, you can easily share state across your Next.js application without the need for external libraries, making it a great choice for smaller to medium-sized projects.

# Using Redux

In this section, we'll explore using Redux, a popular state management library, to manage the global state in our Next.js application.

## Integrating Redux

1. **Install Dependencies**:
   ```bash
   yarn add redux react-redux
   ```

   We'll also install the Redux DevTools extension for debugging:

   ```bash
   yarn add -D redux-devtools-extension
   ```

2. **Initialize the Redux Store**:
   In `redux/store.js`:
   ```jsx
   import { useMemo } from 'react';
   import { createStore, applyMiddleware } from 'redux';
   import { composeWithDevTools } from 'redux-devtools-extension';

   let store;

   const initialState = {};

   // Define the reducer
   const reducer = (state = initialState, action) => {
     // Implement the reducer logic
     switch (action.type) {
       case 'INCREMENT':
         // Update the state
         return { ...state, [action.id]: (state[action.id] || 0) + 1 };
       case 'DECREMENT':
         // Update the state
         return { ...state, [action.id]: Math.max((state[action.id] || 0) - 1, 0) };
       default:
         return state;
     }
   };

   // Initialize the store
   function initStore(preloadedState = initialState) {
     return createStore(
       reducer,
       preloadedState,
       composeWithDevTools(applyMiddleware())
     );
   }

   export const initializeStore = (preloadedState) => {
     let _store = store ?? initStore(preloadedState);

     // Hydrate the store on the server-side
     if (preloadedState && store) {
       _store = initStore({
         ...store.getState(),
         ...preloadedState,
       });
       store = undefined;
     }

     // Return the store instance
     if (typeof window === 'undefined') return _store;
     if (!store) store = _store;
     return _store;
   };

   export function useStore(initialState) {
     return useMemo(() => initializeStore(initialState), [initialState]);
   }
   ```

3. **Wrap the App with the Redux Provider**:
   In `pages/_app.js`:
   ```jsx
   import Head from 'next/head';
   import { Provider } from 'react-redux';
   import { useStore } from '../redux/store';
   import Navbar from '../components/Navbar';

   function MyApp({ Component, pageProps }) {
     const store = useStore(pageProps.initialReduxState);

     return (
       <>
         <Head>
           <link href="https://unpkg.com/tailwindcss@^2/dist/tailwind.min.css" rel="stylesheet" />
         </Head>
         <Provider store={store}>
           <Navbar />
           <div className="w-9/12 m-auto pt-10">
             <Component {...pageProps} />
           </div>
         </Provider>
       </>
     );
   }

   export default MyApp;
   ```

## Using Redux in Components

1. **Integrate Redux Hooks**:
   In `components/ProductCard.js`:
   ```jsx
   import { useDispatch, useSelector, shallowEqual } from 'react-redux';

   function useGlobalItems() {
     return useSelector((state) => state, shallowEqual);
   }

   function ProductCard({ id, name, price, picture }) {
     const dispatch = useDispatch();
     const items = useGlobalItems();
     const productAmount = items?.[id] ?? 0;

     // Handle increment/decrement actions
     const handleIncrement = () => {
       dispatch({ type: 'INCREMENT', id });
     };
     const handleDecrement = () => {
       dispatch({ type: 'DECREMENT', id });
     };

     return (
       <div>
         {/* Render the product card */}
         <div className="flex justify-between mt-4 w-2/4 m-auto">
           <button
             className="pl-2 pr-2 bg-red-400 text-white rounded-md"
             disabled={productAmount === 0}
             onClick={handleDecrement}
           >
             -
           </button>
           <div>{productAmount}</div>
           <button
             className="pl-2 pr-2 bg-green-400 text-white rounded-md"
             onClick={handleIncrement}
           >
             +
           </button>
         </div>
       </div>
     );
   }
   ```

2. **Update the Navbar**:
   In `components/Navbar.js`:
   ```jsx
   import Link from 'next/link';
   import { useSelector, shallowEqual } from 'react-redux';

   function useGlobalItems() {
     return useSelector((state) => state, shallowEqual);
   }

   function Navbar() {
     const items = useGlobalItems();
     const totalItemsAmount = Object.keys(items)
       .map((key) => items[key])
       .reduce((x, y) => x + y, 0);

     return (
       <div className="w-full bg-purple-600 p-4 text-white">
         <div className="w-9/12 m-auto flex justify-between">
           <div className="font-bold">
             <Link href="/" passHref>
               <a>My e-commerce</a>
             </Link>
           </div>
           <div className="font-bold underline">
             <Link href="/cart" passHref>
               <a>{totalItemsAmount} items in cart</a>
             </Link>
           </div>
         </div>
       </div>
     );
   }

   export default Navbar;
   ```

3. **Implement the Cart Page**:
   In `pages/Cart.js`:
   ```jsx
   import { useSelector, shallowEqual } from 'react-redux';
   import data from '../data/items';

   function getFullItem(id) {
     const idx = data.findIndex((item) => item.id === id);
     return data[idx];
   }

   function Cart() {
     const items = useSelector((state) => state, shallowEqual);
     const total = Object.keys(items)
       .map((id) => getFullItem(id).price * items[id])
       .reduce((x, y) => x + y, 0);
     const amounts = Object.keys(items).map((id) => ({
       item: getFullItem(id),
       amount: items[id],
     }));

     return (
       <div>
         <h1 className="text-xl font-bold">Total: ${total}</h1>
         <div>
           {amounts.map(({ item, amount }) => (
             <div key={item.id}>
               x{amount} {item.name} (${amount * item.price})
             </div>
           ))}
         </div>
       </div>
     );
   }

   export default Cart;
   ```

## Key Considerations

1. **Server-Side Rendering (SSR)**: Ensure the Redux store is properly hydrated on the server and client sides. The `initializeStore` function in the `store.js` file handles this.

2. **Scalability**: Redux is better suited for larger applications with complex state management needs. The centralized store and predictable state updates make it easier to manage global state as the application grows.

3. **Performance**: While Redux can handle high-frequency state updates, the Context API may be more efficient for simple global state scenarios that don't require the full Redux ecosystem.

4. **Ecosystem**: Redux has a vast ecosystem of plugins, middleware, and debugging tools that can enhance the developer experience and state management capabilities.

By using Redux, you can manage the global state in your Next.js application with a more structured and scalable approach, especially for larger projects. The combination of Redux and Next.js provides a powerful state management solution for your web applications.
